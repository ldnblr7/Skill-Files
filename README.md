# Skill-Files
Skill Files I have developed, tested, and implemented in my workplace.

Focus: Research and visualization on historical data from 1827-1829. 

critical-challenger.md: Constructively critiques the user's proposal to reduce cognitive biases and distoritions.
  Uses: All stages of data visualization process, from ideation to final design.

verification.md: Verifies the historical sources and information, identifying any discrepancies and correcting them, then giving a summary of verification status, method, and limitations.
  Uses: Collection of historical data from sources uploaded directly, verified sources via the internet, or internally connected files. 

source-finder.md: Gathers reported sources and the sources found therein, gives full-depth report with direct links when applicable.
  Uses: Collection of original sources from Saints Volume 1.
